# Endpoints

Each API operation is one method on the client, named from its operation ID and grouped here by API area. Examples use the `ak_test` key and placeholder identifiers; replace them with your own before running.

## Address Search

- [`addressVerify()`](https://docs.addresszen.com/docs/sdks/php/endpoints/address-verify): Verify Address
- [`findAddress()`](https://docs.addresszen.com/docs/sdks/php/endpoints/find-address): Find Address
- [`retrieveAddress()`](https://docs.addresszen.com/docs/sdks/php/endpoints/retrieve-address): Retrieve Address
